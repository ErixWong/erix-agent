## C. tools 子路径（worker-C）

package.json 已映射 `"./tools": "./src/tools/index.js"`。全部零依赖纯 node（rg/tree 自己实现，不调外部命令）。

### src/tools/jail.js

```js
export class JailError extends Error { code = "jail_violation" }
export function createJail({ root, writable = [], maskedPaths = [] })
// → { resolve(p), resolveForWrite(p), assertReadable(p) }
// resolve：path.resolve(root, p) + fs.realpathSync 解符号链接（文件不存在时 realpath 其父目录），
//   结果必须在 root 内否则 throw JailError("path_escapes_root")
// resolveForWrite：resolve 后还须在某个 writable 子树内（writable 为相对 root 的前缀列表），否则 throw("path_not_writable")
// assertReadable：resolve 后命中 maskedPaths（相对 root 前缀，如 [".git", "node_modules"]）→ throw("path_masked")
```

### src/tools/file-tools.js

```js
export function createFileTools(jail) // → { schemas: ToolSchema[], executors: { readFile, rg, tree, writeFile } }
// readFile({path, offset?, limit?})：按行返回，默认前 200 行，带行号与总量路标（"[共 N 行，offset=200 继续]"）
// rg({pattern, path?, maxResults?=50})：递归文本搜索（跳过 maskedPaths/二进制/大文件>1MB），返回 文件:行号:行内容
// tree({path?, depth?=3})：目录树文本（跳过 maskedPaths），条目数上限 500
// writeFile({path, content})：resolveForWrite 后写入（自动 mkdir -p），返回字节数
// schemas 为规范 ToolSchema（{name, description, inputSchema}）
```

### src/tools/registry.js（ADR-006）

```js
export function createToolRegistry({ executors, schemas })
// → { executeTool(name, input), resolveTools(provider, sel) }
// executeTool：先按 schemas 最小校验（required 缺参/type 不符/maxLength 超）→ 校验失败**返回错误字符串，不调用执行器**；

//   inputSchema 约束（仅允许收紧：maxLength 更小/required 更多），交集结果与注册表 schemas 合并返回
```

### src/tools/recall.js（ADR-007：pattern 优先）

```js
export function createRecallTool({ store, runId, limits = {} })
// → { schema: ToolSchema, execute: (input) => Promise<string> }
// input：{ pattern?, fromRound?, toRound?, offset? }（episodeId 留 v1.x，不出现在 schema）
// 无参数 → 轮次概览：每轮一行（round/folded 标记/消息数/工具名摘要）+ 折叠水位线
// pattern → 优先路径：全范围搜索，grep -C 摘录（命中行 ±2 行），单段 ≤300tok，最多 5 段，总 ≤1500tok（limits 可覆盖）；
//   命中文本化规则与 store.recall 一致；超顶带路标 "[截断，共 N 段，offset=5 继续]"
// fromRound/toRound → 范围原文（每轮消息文本化，同样过总量硬顶与路标）
// 空结果 → "未命中。建议换更短的关键词或同义词重试"
// 文本化：text 块取 text；tool_use 取 name+JSON.stringify(input)；tool_result 取 content
```
