# 定期文档检查（由 agent 跑，不是闸）

> 英文版：[doc-review-pass.md](doc-review-pass.md)。

**裁决（261109，用户决定）。** 文档检查**不做 CI 闸、也不做发版前置步骤**。脚本能判的只有措辞——「这句必须
存在」「中英出现次数必须相等」——而这一类判据在 PR 上造出 25% 的红率，却几乎抓不到真缺陷（实测：200 次运行
138 成功 / 49 失败 / 13 取消；抽样 12 次失败里 9 次是「提交进库的表与树对不上」，真测试只红 1 次）。真正值钱的
两类——**引用完整性**（文档指向一个已经不存在的文件）与**派生值抄件**（文档引用的版本号/计数，源码已经不这么说）
——改由 **agent 定期读文档**来找，因为「这句话现在还对不对」是判断，不是正则。

## 什么时候跑

- 由操作者定周期（约定的是每周一次），以及
- 发版前**如果**操作者想要第二双眼睛（发版本身不再因它阻塞）。

## agent 要跑的命令

一条命令收齐机械那一半；agent 读输出，但不信它：

```bash
npm run docs:pass
```

它依次跑：`check:docs`（漂移 + 中英骨架 + 版本声称 + 引用路径）、`check:docs:strict`、`check:docs:spelling`、
`check:docs:examples`、`check:agents-directives`，以及 drift 检查器自己的 `--self-test`。
**它的退出码是关于脚本的证据，不是关于文档的证据**——脚本看不见「看起来对但其实错了」的句子。

## agent 必须手工判的（这才是检查本体）

1. **默认值**——两份 README、两份 `AGENTS*.md`、两份契约文档里每一句 `default X` / `默认 X`，对着源码常量或
   CLI 帮助文本读一遍。#614 换掉了 CLI 槽位的默认折叠策略，**所有机器闸全绿**——这一类只有读者能抓。
2. **数字**——步数、条目数、表大小、`N of them` 这类声称。拿文档自己点名的那条命令去核，并真的跑一遍。
3. **名称集合**——策略名、工具名、旗标名、选项键。一个改过名的旋钮留在散文里，是代价最高的过期句。
4. **版本声称**——「当前版本」「发布行」「从未发布」这类句子，对着 `package.json`、
   `npm view <pkg> dist-tags.latest` 与 `git tag` 核。
5. **引用完整性**——活文档里每个 `path/to/file` 与每个 `#anchor`：解析得到吗？（`check:docs` 在它扫的那一面
   覆盖了文件那一半；agent 覆盖其余部分，包括跨仓的 `<repo>:<path>` 引用。）
6. **退役语义**——代码已经不做了、文档还在承诺的事。读最近两个版本的 CHANGELOG Breaking 段，逐条确认它已经
   反映在宿主会看的地方。
7. **CHANGELOG 成对条目**——在**中英两侧同时**消失的条目。配对判据只证「每条中文都有英文对应」与其反向，
   它不登记任何计数（那个 `CHANGELOG_PAIR_FLOOR` 已在 PR #826 删掉，因为它每开一个发布窗口就作废一次），
   所以「一整对被删掉」是这一遍要判的，不是机器能判的。把该节与它本该点名的合并号对照着看
   （`npm run check:changelog` 兜的是「点名过的合并号」那一半）。

## 怎么报

- 一条发现一行：`文件:行 — 文档怎么说 — 真相是什么 — 证明它的命令`。
- 没有命令的发现不算发现；「看起来旧了」不是发现。
- 发现是**提案**：除非操作者同一句话里要了修复，agent 不擅自改文档。
- 一趟下来没发现问题，就明确说没发现，并点名读了哪些（沉默的「一切正常」与「我什么都没读」无法区分）。

## 仍然自动化的那些，以及为什么它们不算「文档检查」

| 闸 | 为什么留着 |
|---|---|
| `check:agents-directives` 的字节预算 + 状态句/过期抄件/裸坐标三类 | 指令面每轮全额重发：**长度**就是成本，而写在上面的状态句会被当成事实执行。棘轮数字一律 `--sync` 刷，不许手写。 |
| `check:inventory` / `check:config-leaf-values` / `check:mutation` | 它们比的是**提交进库的表与树**——派生值，由探针重新生成。这里没有一处判散文；`--sync` 是唯一合法的更新路径。 |
| `check:pack-links` | 随包 Markdown 的链接必须解析得到；随包 README 里一条死链是坏产物，不是过期句。 |
| `check:changelog` | 碰到公开面的合并没有 CHANGELOG 条目是**缺记录**，不是措辞问题。 |
| `check:test-summary` | 防的是「套件悄悄不跑了」（skip / 退出码），不是散文。 |

以前挂在「docs」名下的其余一切——`check:docs` 的散文要求、中英处数普查、「这句必须存在」那几族——已由
issue #802 删除。`check:docs` 仍然存在，作为**手动工具**（`npm run docs:pass`），只是不再拦任何东西。
